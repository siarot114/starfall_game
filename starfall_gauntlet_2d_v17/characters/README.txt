Drop-in character art (optional)
================================
Put your own portraits here and the game uses them automatically instead of the built-in drawings:

  vega.png   nova.png   tyrant.png   kael.png   mira.png   queen.png   hayato.png   yuzu.png   daichi.png

Tips: square PNGs, 512x512 recommended, transparent or solid background, face centred.
Any file that is missing falls back to the built-in portrait.

Pilots with portraits: HAYATO, YUZU, DAICHI also work as playable pilots (Crew screen). Story characters keep using the files above.
